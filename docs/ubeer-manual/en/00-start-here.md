# uBeer Manuals and Launch Kit

Use the guide that matches your role. The web app is also the mobile experience: install it on iPhone or iPad from Safari using Share → Add to Home Screen, install it from Chrome on Android, or download the Android APK from the home page.

## Documents

- [Customer guide](01-customer-guide.md): check service, place and pay for an order, track it, and complete delivery.
- [Driver guide](02-driver-guide.md): apply, sign in after approval, work assignments, and review earnings.
- [Admin guide](03-admin-guide.md): secure sign-in, regions, catalog, orders, drivers, users, payouts, and audit history.
- [Promotional kit](04-promotional-kit.md): approved draft descriptions, campaign messages, and publication checks.
- [Launch and operations guide](05-launch-and-operations.md): overseas market readiness, support answers, BTCPay, and service operations.

## Read before using these guides

The live environment is a prototype configured for Montréal Island, Québec. Its seeded six-pack of Heineken is marked TEST LISTING and priced at $30.00 USD, plus the configured delivery fee. No overseas service regions are configured. Address lookup currently accepts Canadian results only and uses a Montréal-area search view. The checkout currency is USD. These are prototype settings, not a statement about future market availability.

The interface includes English, French, Italian, Spanish, Simplified Chinese, and Russian. This documentation is provided in English, French, Spanish, Italian, and Russian. Review app text, support workflows, local terms, and legal notices with native speakers and qualified local advisers before each launch.

**Do not use the current test catalog or Montréal boundary for commercial delivery.** Follow the launch checklist before publishing market-specific prices or making delivery, age-verification, legal, or payment-method claims.
