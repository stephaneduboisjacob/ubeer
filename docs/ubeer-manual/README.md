## Accuracy and launch status

These guides describe the current uBeer prototype and identify items that require configuration or product work before launch in another country. The currently configured Montréal region and Heineken listing are test data. The address lookup is restricted to Canada and a Montréal-area view box; checkout currency is USD; region age-gate choices are currently 19 or 21; and the admin map drawing control is not connected. Do not treat the prototype as available for overseas orders until those constraints are addressed and each target market has been reviewed.

Marketing copy is a draft. Claims about 24-hour delivery, 2,000+ cryptocurrencies, service coverage, local licensing, age checks, and delivery times must be verified for the specific launch region before publication.
