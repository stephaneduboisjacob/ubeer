# Montréal Island delivery polygon

`montreal-island.geojson` is a GeoJSON `Polygon` sourced from the OpenStreetMap relation for Île de Montréal (relation 3430571) using the Nominatim search API on 2026-10-02. The closed coastline ring was simplified with a roughly 9–13 metre tolerance to keep point-in-polygon checks and Leaflet rendering responsive. The API uses this geometry as the authoritative delivery gate; the web artwork is decorative only.

Attribution: © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright), available under the Open Database License (ODbL). This simplified polygon defines the configured Montréal Island delivery area and should be reviewed against operational delivery limits.
