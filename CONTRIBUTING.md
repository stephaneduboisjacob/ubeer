# Contributing

Read the README and relevant operator manual before changing order, delivery-area, payment, or account flows. Open an issue with a concise description and a reproducible example before proposing a broad change.

Use the checked-in npm lockfile. Do not commit `.env`, Android signing material, keystores, uploads, customer or driver identity documents, payment credentials, or production logs. Use fictional test records and provider sandboxes.

Available checks include `npm run typecheck`, `npm run lint`, `npm test`, and `npm run build`. Note which checks you ran.
